ABSTRACT

A bicycle assembly can have a main frame, a Sub-frame, a
main shock section, an extension section, and a fastener. The
Sub-frame can move in relation to the main frame and the

main shock section can be used to regulate that relationship.
The extension section can have a receiving portion, wherein
an end of the main shock section can fit into the receiving
portion. The fastener can be used to secure the main shock
section within the receiving portion of the extension section.
